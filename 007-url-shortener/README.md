# go-http-server

A URL shortener built with the Go standard library (Go 1.22+), structured like a real Go service. Heavily commented as a `net/http` reference.

## Run

```bash
go run ./cmd/api          # :8080 (override with PORT=9000)
```

```bash
curl -i -X POST localhost:8080/api/shorten \
  -H 'Content-Type: application/json' -d '{"url": "https://go.dev/blog"}'
curl -i localhost:8080/<code>          # follow the redirect
```

## Routes

| Method | Path            | Purpose                  |
|--------|-----------------|--------------------------|
| GET    | `/healthz`      | health check             |
| POST   | `/api/shorten`  | create a short link      |
| GET    | `/{code}`       | redirect to original URL |

```bash
# health
curl -i localhost:8080/healthz

# create (returns a code)
curl -i -X POST localhost:8080/api/shorten \
  -H 'Content-Type: application/json' -d '{"url": "https://go.dev/blog"}'

# follow the redirect (302)
curl -i localhost:8080/<code>

# validation: bad URL -> 400
curl -i -X POST localhost:8080/api/shorten -d '{"url": "not-a-url"}'

# unknown code -> 404
curl -i localhost:8080/nope

# wrong method -> 405
curl -i -X DELETE localhost:8080/api/shorten

# rate limit -> some 429s
for i in $(seq 1 30); do curl -s -o /dev/null -w "%{http_code}\n" localhost:8080/healthz; done
```

## Layout

- `helpers/` — base62 code generation
- `models/` — `URLStore` interface; in-memory + Postgres implementations
- `controllers/` — parse → store → respond, with sentinel-error translation
- `middleware/` — request ID, logging, recovery, rate limiting
- `routes/`, `config/`, `cmd/api/` — routing, env config, wiring + graceful shutdown

## Postgres (optional)

```bash
docker compose up -d db
make migrate-up
DATABASE_URL='postgres://shortly:shortly@localhost:5432/shortly?sslmode=disable' go run ./cmd/api
```

No `DATABASE_URL` falls back to the in-memory store. `db/` is generated by sqlc (`make sqlc`) — don't edit it.
